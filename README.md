# FSAE Tools

The collection landing page is published at [sida0.github.io/fsae-tools/](https://sida0.github.io/fsae-tools/). It links to the six current Formula SAE workspaces for frame fabrication, rules reference, and exhaust work.

GitHub Pages serves `index.html` and `tools.css` from the root of `main`. This repository owns the directory; each tool remains in its own repository.

## Add a tool

1. Add a linked `.tool-card` to the appropriate section in `index.html`, using the tool's actual name, function, and URL.
2. Add an **All tools** link to the tool's header pointing to `https://sida0.github.io/fsae-tools/`.
3. Use the shared dark palette and typography in the tool's own stylesheet.
4. Update the count in the directory navigation and page description. Check the landing page at 1440 px and 390 px widths, including every card link.
